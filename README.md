# ردّآلي - منصة ذكاء صناعي لإدارة المحادثات والطلبات والمبيعات

منصة متكاملة تربط جميع قنوات التواصل (واتساب، ماسنجر، إنستغرام، تلغرام، شات الموقع، SMS، بريد، تيك توك، Google Business) وتستخدم الذكاء الصناعي للرد على العملاء تلقائيًا، استلام الطلبات، وإدارة المبيعات.

## المميزات

- **صندوق وارد موحّد** لكل القنوات في مكان واحد
- **ذكاء صناعي** يرد، يبيع، ويحوّل المحادثات إلى طلبات
- **إدارة طلبات كاملة** من الإنشاء للتسليم
- **استوديو ذكاء** لتدريب وضبط المساعد الذكي
- **أتمتة متقدمة** بقواعد و Workflows
- **تحليلات وتقارير** لحظية
- **إدارة فريق** بصلاحيات دقيقة
- **بوابة تتبع** للزبون النهائي
- **لوحة إدارة عليا** للمنصة
- **دعم متعدد المزودات**: OpenAI، OpenRouter، Hugging Face

## التقنيات

- React 18 + TypeScript + Vite
- Tailwind CSS
- Supabase (قاعدة بيانات + مصادقة + RLS)
- Recharts للرسوم البيانية
- Lucide React للأيقونات

## التشغيل المحلي

```bash
npm install
cp .env.example .env  # املأ المتغيرات
npm run dev
```

## النشر على Railway

1. اربط المستودع بـ Railway
2. اضبط متغيرات البيئة من `.env.example`
3. Railway سيبني وينشر تلقائيًا

## قاعدة البيانات

شغّل ملف `database/schema.sql` على Supabase SQL Editor لإنشاء جميع الجداول.

## البناء

```bash
npm run build
npm run typecheck
```
